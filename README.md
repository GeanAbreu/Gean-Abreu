## 🚀 Projeto em destaque

### 🔧 SmartFix

O **SmartFix** é uma plataforma web desenvolvida para conectar **clientes e assistências técnicas**, centralizando o processo de solicitação, gerenciamento e acompanhamento de reparos em dispositivos eletrônicos.

O projeto está sendo desenvolvido utilizando uma arquitetura organizada entre frontend, API, regras de negócio e banco de dados.

### Tecnologias utilizadas

- **Next.js**
- **React**
- **TypeScript**
- **JavaScript**
- **Node.js**
- **PostgreSQL**
- **Sequelize ORM**
- **HTML**
- **CSS**
- **APIs REST**
- **Arquitetura MVC**

### Arquitetura

```text
Frontend
    ↓
Next.js API
    ↓
Routes
    ↓
Controllers
    ↓
Models Sequelize
    ↓
PostgreSQL
```
Entre as funcionalidades e conceitos trabalhados no projeto estão:

- Cadastro de clientes;
- Autenticação de usuários;
- Integração entre frontend e backend;
- Criação e consumo de APIs;
- Estruturação de Models, Controllers e Routes;
- Integração com PostgreSQL através do Sequelize;
- Validação de dados;
- Organização utilizando arquitetura MVC;
- Gerenciamento de sessões;
- Proteção de senhas;
- Cadastro de endereços;
- Estrutura para clientes, dispositivos e assistências técnicas;
- Tratamento de erros;
- Separação de responsabilidades no backend.
